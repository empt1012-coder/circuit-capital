Tools

Nine checklists and calculators. Each one runs in the browser. Nothing is uploaded. Each also has a free download: a CSV, spreadsheet, PDF or checklist.

These tools exist because the same few calculations come up again and again in the briefings, and doing them by hand in a meeting is where mistakes happen. Each tool turns one recurring decision into a short form: score a renewal, write an agent’s permission list, request an SBOM, test a vendor’s savings claim, price a task an AI model finishes, or record who decided a cyber incident was material. They are written for the people who make those calls — finance leads, IT and procurement owners, security managers and founders — rather than for specialists who already have dedicated software.

Every tool runs entirely in your browser. Nothing you type is uploaded or stored by us, and you can use each one without an account or an email address. Each tool also has a free download — a CSV template, a spreadsheet with the formulas visible, a PDF or a checklist — so you can keep the result, share it with a colleague, or adapt it to your own numbers. Where a tool relies on an outside rule, such as the SEC’s four-business-day Form 8-K deadline or CISA’s minimum elements for a software bill of materials, the tool page links to the official source so you can check the logic yourself.

How to use them: start with the guide linked from each tool if the decision is new to you, then fill in the tool with your own volumes, prices and dates rather than our examples. Treat the output as a working draft for a decision, not as the decision. The tools are not legal, tax, insurance or procurement advice, and they do not replace your counsel, auditor or broker. If a tool gives an answer you think is wrong, send us the inputs through the contact page; logic errors are fixed and noted the same way as factual corrections.

The nine tools are listed below with a one-line description of what each one produces. Related guides are on the Guides page, and the Topics pages group tools, guides and briefings by decision.

Which tool for which decision

  • A renewal is coming up: software renewal scorecard, then the vendor claim checker if the vendor promises savings.
  • You are deploying an AI agent: agent inventory first, then the agent access limit sheet for each agent.
  • You are pricing AI work: AI model cost per finished task, then token cost to gross margin.
  • A security event or exception: the 8-K materiality worksheet for public companies, and the risk exception register for anything you cannot fix this week.
  • A vendor security review: the SBOM request pack.

Not legal, tax, insurance, or procurement advice. Inputs stay on this device.
